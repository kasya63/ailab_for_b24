# AI Lab (local.ailab) — этап 1: подключения

Что умеет этап 1: хранить подключения к провайдерам ИИ (Anthropic и OpenAI-совместимые: OpenAI, OpenRouter и др.), шифровать API-ключи и проверять подключение пробным запросом со строгим JSON-ответом. Сценарии, очередь и кубик БП появятся на следующих этапах поверх этого же слоя.

## Установка

1. Распакуйте архив в `/home/bitrix/www/local/modules/` так, чтобы получилось `/home/bitrix/www/local/modules/local.ailab/include.php`.
2. Если заливали под своей учёткой, верните владельца:
   `chown -R bitrix:bitrix /home/bitrix/www/local/modules/local.ailab`
3. Админка → Marketplace → Установленные решения → «AI Lab» → Установить.

Установщик:
- создаёт таблицу `local_ailab_connection`;
- создаёт каталог `/home/bitrix/.ailab/` (права 700) и ключ шифрования `secret.key` (права 600) — вне веб-корня;
- копирует страницу `/bitrix/admin/ailab_connections.php`.

Папка `/home/bitrix/www/local/ailab`, созданная заранее, модулю не нужна.

## Первое подключение

Сервисы → AI Lab → Подключения → Добавить подключение → «Сохранить и проверить».

| Провайдер | Адрес API | Модель | Вкладка «Дополнительно» |
|---|---|---|---|
| Anthropic | пусто | `claude-haiku-4-5-20251001` | ничего менять не нужно |
| OpenAI | пусто | из кабинета OpenAI | для новых моделей «Поле лимита токенов» = `max_completion_tokens`; у reasoning-моделей снять «Передавать temperature» |
| OpenRouter | `https://openrouter.ai/api/v1` | как в каталоге OpenRouter, например `anthropic/claude-haiku-4.5` | обычно ничего |

Проверка показывает статус, время, токены, разобранный JSON, а также запрос и ответ провайдера целиком (ключ в запрос не попадает: он уходит только в заголовке). Если провайдер ругается на параметр, под ошибкой появится подсказка, какую настройку сменить.

## Ключ шифрования — в бэкап

`/home/bitrix/.ailab/secret.key` нужен, чтобы расшифровать API-ключи из базы. Выгрузка одной только базы ключи не раскрывает. Если файл потеряется (например, при переезде без каталога `/home/bitrix`), ключи API нужно будет ввести заново — сами подключения сохранятся.

Другой путь для каталога можно задать до установки в `/local/php_interface/init.php`:

```php
define('LOCAL_AILAB_PRIVATE_DIR', '/путь/вне/www');
```

## Удаление

Удаление модуля убирает страницу из `/bitrix/admin` и регистрацию модуля. Таблицы `local_ailab_*` и ключ шифрования остаются, так что при переустановке ничего не теряется. Полностью стереть данные — вручную: `DROP TABLE local_ailab_connection;` и удалить `/home/bitrix/.ailab/`.

## Обновление

Новые этапы приходят архивом поверх этой папки. Новые таблицы создаются сами при первом открытии страницы модуля — переустанавливать не нужно.


## Как модуль добивается строгого JSON

- **Anthropic** — схема передаётся как инструмент, который модель обязана вызвать (`tool_choice`). Работает на всех моделях Claude.
- **OpenAI-совместимые** — `response_format` с JSON Schema (strict), либо упрощённые режимы для провайдеров, которые его не знают.
- **В обоих случаях** ответ дополнительно проверяется на сервере. Обрезанный ответ, отказ модели или ответ без JSON получают статус `invalid`; сетевые сбои и 429/5xx — статус `error` с пометкой, что повтор имеет смысл.
